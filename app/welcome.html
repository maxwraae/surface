Surface is running.

A browser that gives the web local files. Connect an AI agent and it can show you anything in a window.

First-time setup — paste this into your AI agent (or run it in a terminal):

npx -y surface-mcp install

Then ask the agent to open something — a file, a URL, or anything it wants to show you visually.

From Finder: right-click an .html file → Open With → Surface.

This window is just the welcome page. You can close it anytime — Surface stays running in the background and opens new windows when called.
